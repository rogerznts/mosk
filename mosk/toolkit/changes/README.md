## Chore Changes

Esta pasta armazena mudancas rapidas do fluxo `mosk-chore-*`.

Estrutura recomendada:

- `toolkit/changes/<change-id>/proposal.md`
- `toolkit/changes/<change-id>/tasks.md`
- `toolkit/changes/<change-id>/design.md` (opcional)
- `toolkit/changes/archive/<change-id>/` (historico manual opcional)

Observacao: o encerramento em `archive` nao faz merge automatico de specs.
