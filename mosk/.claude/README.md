# MOSK no Claude Code (Skills)

No Claude Code, os comandos do MOSK sao skills em:
- `.claude/skills/<skill>/SKILL.md`

Cada skill vira um comando slash com o nome definido no frontmatter (`name`).
Exemplo: `name: mosk-spec-specify` -> comando `/mosk-spec-specify`.
